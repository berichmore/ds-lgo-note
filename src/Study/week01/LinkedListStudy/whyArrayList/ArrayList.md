---

### 🔍 Step 1. ArrayList가 뭔데?

| 항목                                          | 설명 |
| ------------------------------------------- | -- |
| ✅ **동적 배열 (Dynamic Array)**                 |    |
| → 내부적으로 배열을 쓰지만, 배열보다 유연하게 **크기가 자동으로 늘어남** |    |
| ✅ **인덱스로 빠르게 접근 가능**                        |    |
| → `get(3)` 같은 거는 배열처럼 바로 찾아갈 수 있음           |    |
| ✅ \*\*끝에 추가(add)\*\*는 빠르고,                  |    |
| \*\*중간에 삽입/삭제(remove)\*\*는 느림 (당겨야 하니까)     |    |

---

### 🔍 Step 2. 왜 우리가 직접 만들어봐야 해?

| 이유                            | 설명                                   |
| ----------------------------- | ------------------------------------ |
| Java가 제공하는 `ArrayList`는 블랙박스야 | 쓰긴 쉽지만 내부가 어떻게 동작하는지 모르면 버그 고치기도 힘들어 |
| 실무에서 커스텀 자료구조 만들어야 할 때가 많아    | 배열을 직접 컨트롤할 줄 아는 게 큰 강점              |
| 메모리, 시간복잡도, 최적화 감각을 얻을 수 있어   | 자동 확장, shift 처리 등                    |

---

### 🔍 Step 3. 우리가 구현할 최소 기능 목록

```java
add(int value);     // 끝에 값 추가
get(int index);     // index번째 요소 반환
set(int index, int value); // index번째 요소 수정
remove(int index);  // index번째 요소 삭제
size();             // 현재 요소 개수
toString();         // 리스트 상태 출력
clear();            // 전체 비우기
contains(int value);// 특정 값이 있는지 확인
```

## ✍️ Jay의 메모로 정리해보자

> 우리가 만들 `MyArrayList`는
> 내부적으로 배열(int\[])을 사용하면서도
> 배열처럼 직접 관리하지 않아도 되는 편의 기능을 제공한다.
>
> Java의 `ArrayList`처럼 동작하지만,
> 내부 배열 크기, 요소 개수, 확장 로직을 내가 직접 짜면서
> 자료구조의 동작 원리를 몸으로 체화할 수 있다.
